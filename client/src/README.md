# Frontend structure

- `app/`: application shell, routes, pages, and page-level state.
- `components/`: reusable presentational UI components (add shared components here).
- `config/`: environment and third-party browser configuration.
- `hooks/`: reusable React hooks.
- `pages/`: route-oriented page modules (add future split page modules here).
- `services/`: API and browser service integrations.
- `styles/`: global CSS and design-system styles.
